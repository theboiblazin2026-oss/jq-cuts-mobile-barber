# 💈 JQ Cuts — Master Barber Mobile Web Application

> Luxury mobile barbershop website for **JQ Cuts Master Barber (Jaquan)**. Built with React, TypeScript, Tailwind CSS v4, and Lucide Icons.

---

## ✨ Features

- **🏆 Brand Emblem Integration**: Directly incorporates the official 3D metallic gold and chrome silver logo, Est. 2024 badge, and Barber Pole accents.
- **📅 Apple / iPhone Calendar (.ics) Sync**:
  - Automatically generates RFC-5545 standard `.ics` iCalendar invites containing complete appointment data: Service name, price, client contact, address, notes, and 1-hour alarm notification.
  - One-click Google Calendar export link with pre-filled event parameters.
- **📲 Dual SMS Notification Engine**:
  - Prepares structured confirmation text messages for both the **Client** and **Master Barber Jaquan** (`912-286-1805`).
  - Includes a 1-tap native iOS / Android SMS link opener (`sms:9122861805?...`).
- **✂️ Interactive VIP Service Menu**:
  - Category filters: VIP Experiences, Haircuts, Beard & Shave, Group/Wedding Specials.
  - Transparent pricing, estimated durations, and custom add-ons (Charcoal mask, enhancements, eyebrow straight razor arch).
- **📍 Georgia 912 Territory Coverage**:
  - Coverage details for Waycross, Savannah, Brunswick, Hinesville, Jesup, and surrounding areas.
- **📸 Haircut & Lineup Portfolio**:
  - Visual gallery filterable by Skin Fades, Beards, Tapers & Waves, and Freestyle Designs.
  - Direct connection to Instagram **[@JAQUAN3950](https://instagram.com/JAQUAN3950)**.
- **⭐ Verified 5-Star Reviews**:
  - Customer feedback highlighting punctuality, zero-commute convenience, and sterile hospital-grade sanitization.
- **📱 Sticky Mobile Bottom Bar**:
  - Fast one-thumb access to Call, SMS, Book Now, Price Menu, and Instagram.
